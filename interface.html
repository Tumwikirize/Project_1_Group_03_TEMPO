User Interface Design

This page presents the proposed user interface for TEMPO, including wireframes of its main pages and modal dialogs. It describes the interface components, navigation structure, user interactions, and design decisions, with an emphasis on usability and accessibility.

1. Interface Overview

TEMPO's user interface is designed to provide convenient access to activity management, time logging, and progress tracking. The interface organizes these features into separate pages connected by a shared navigation sidebar, with modal dialogs for common actions such as creating activities and recording time.

1.1 Design Goals

The interface is designed with simplicity, efficiency, consistency, and accessibility in mind. Its primary design goals include:

  • Simplicity: Keep pages organized and avoid unnecessary complexity or clutter.
  • Efficiency: Minimize the steps required for common actions, particularly logging time and managing activities.
  • Consistency: Maintain a consistent layout, navigation structure, and set of controls throughout the application.
  • Clarity: Present activity progress and statistics using clearly labeled numerical values, progress bars, and graphs.
  • Accessibility: Support keyboard navigation, readable text, descriptive labels, and text-based alternatives to visual information.

1.2 Navigation Structure

TEMPO uses a persistent sidebar to provide navigation between the application's main pages, along with shortcuts for active activities. The sidebar remains consistent throughout the application.

Key Components

  • TEMPO and Dashboard: Navigate to the application's main page, which displays current activity progress and recent time records.
  • Reports & Statistics: Opens the reporting page, where users can review historical progress and statistics.
  • Log Time: Opens the time logging modal from any page.
  • Activities: Displays shortcuts to five frequently accessed activities. Selecting an activity opens its individual details page.
  • View All Activities: Opens the complete activity list, including active, suspended, and archived activities.
  • Create New Activity: Opens the activity creation modal.

Navigation Behavior

  • The sidebar remains visible when navigating between the application's main pages.
  • Activity shortcuts provide direct access to individual activity details without returning to the Dashboard.
  • Activities not displayed in the sidebar remain accessible through the All Activities page.
  • The Log Time and Create New Activity shortcuts open modal dialogs without navigating away from the current page.

2. Page Designs and Wireframes

The following wireframes illustrate the proposed layout and functionality of TEMPO's main pages and modal dialogs. Each design identifies the primary interface components and describes how users interact with them.

2.1 Primary Pages

TEMPO's primary pages include the Dashboard, All Activities, Individual Activity Details, All Time Logs, and Reports & Statistics. These pages allow users to monitor their progress, manage activities, review saved time records, and analyze historical performance.

2.1.1 Dashboard

The Dashboard serves as TEMPO's main landing page, providing an overview of the user's activities, current progress, and recent time records.

Related requirements: FR-02, FR-14, FR-18

Key Components
  • Date and Time: Displays the current date and time in the upper-right corner.
  • Progress Summary: Displays four statistics:
    • Total time logged today.
    • Total time logged during the current week.
    • Number of daily goals achieved.
    • Number of weekly goals achieved.
  • Activity Cards: Display active activities and their current daily or weekly goals. Each card includes the activity name, target duration, progress bar, recorded time, remaining time, and a logging button. Suspended and archived activities remain accessible through the All Activities page, which displays their statuses and current goals.
  • Recent Logs: Displays the most recent time records, including the activity, date, duration, notes, and an edit option.
User Interactions
  • Click an activity to open its individual details page.
  • Click + Log Time (present on the activity cards) to open the logging modal with the corresponding activity selected.
  • Click View All Activities to access the complete activity list.
  • Click + Log Time (above the Recent Logs section) to open the logging modal with no activity selected.
  • Click View All Time Logs to access the complete time record history.
  • Click a time record's notes field to view its details, displaying the activity, date, duration, and full notes.
  • Click an edit icon to modify an existing time record.

2.1.2 All Activities

The All Activities page provides a complete list of the user's activities, including active, suspended, and archived activities. Users can browse and manage their activities from this page.

Related requirements: FR-02, FR-06, FR-07, FR-19

Key Components
  • Search Bar: Allows users to search for activities by name.
  • Status Filter: Allows users to display all activities or filter by active, suspended, or archived status.
  • Activity Table: Displays the user's activities with the following information:
    • Activity name.
    • Current daily or weekly target.
    • Date of the most recent time record.
    • Activity status.
    • Edit button.
  • Sorting Controls: Allow users to organize activities by most recent time record.
  • Create New Activity: Opens the activity creation form.
  • + Log Time: Opens the time logging modal.
User Interactions
  • Enter text in the search bar to find activities by name.
  • Select a status to display active, suspended, archived, or all activities.
  • Click a column's sorting control to change the order of the displayed activities.
  • Click an activity name to open its individual details page.
  • Click the + button beside the activity name to log time for that specific activity.
  • Click an edit icon to open the activity editing modal.
  • Click + Create New Activity to open the activity creation modal.
  • Click + Log Time to open the time logging modal.

2.1.3 Individual Activity

The Individual Activity (or just Activity) page provides a detailed view of a selected activity, including its current goal, historical progress, statistics, and recent time records. Users can also manage the activity and its associated time records.

Related requirements: FR-05, FR-13, FR-14, FR-15, FR-16, FR-20

Key Components
  • Activity Information: Displays the activity name and current status.
  • Current Progress: Displays the current daily or weekly target, time logged, remaining time, and a progress bar.
  • Statistics: Displays the total time logged, average daily time, and number and percentage of targets achieved.
  • Progress Graph: Displays historical progress using a bar or line graph. Users can view recorded time or the percentage of the target achieved over a selected date range.
  • Recent Logs: Displays the five most recent time records for the activity, including dates, durations, notes, and editing controls.
User Interactions
  • Click Edit Activity to open the activity editing modal with this specific activity pre-selected.
  • Click + Log Time to open the logging modal with the current activity automatically selected.
  • Use the graph controls to switch between bar and line graphs, select a reporting period, and view time or target progress.
  • Click View All Reading Time Logs to open the All Time Logs page filtered to the selected activity.
  • Click a time record's notes field to view its details, displaying the activity, date, duration, and full notes.
  • Click an edit icon beside a time record to open the Edit Log modal.

2.1.4 All Time Logs

The All Time Logs page displays the user's complete history of recorded time entries across all activities. Users can browse, filter, and manage their saved time records.

Related requirements: FR-10, FR-11, FR-12, FR-13

Key Components
  • Activity Filter: Allows users to display time records for all activities or a specific activity.
  • Date Filter: Allows users to select a date or date range to narrow the displayed records.
  • Time Log Table: Displays saved time records with the following information:
    • Activity name.
    • Date and time of the recorded session.
    • Duration of the session.
    • Optional notes.
    • Edit button.
  • Pagination Controls: Allow users to navigate between pages of time records.
  • Scroll Wheel: Allow users to scroll through currently selected page of time records.
  • Log Time Button: Opens the time logging modal to create a new record.
User Interactions
  • Select an activity from the dropdown to display only its associated time records.
  • Use the date filter to display records from a selected date or date range.
  • Scroll through the displayed time records and use the pagination controls to view additional entries.
  • Click an activity name to open its individual details page.
  • Click a time record's notes field to view its details, displaying the activity, date, duration, and full notes.
  • Click an edit icon to open the Edit Log modal with the selected record's existing information.
  • Click + Log Time to open the time logging modal and create a new record.

2.1.5 Reports & Statistics

The Reports & Statistics page provides an overview of the user's progress across activities, including time totals, averages, historical trends, and future projections. Users can filter reports by activity and date range to examine their progress in greater detail.

Related requirements: FR-14, FR-15, FR-16, FR-17, FR-18, FR-20, NFR-05

Key Components
  • Current Progress: Displays four summary statistics for the selected activities and date range:
    • Total time logged.
    • Average daily time logged.
    • Number of sessions logged.
    • Goal adherence rate.
  • Progress Graph: Displays historical progress using a bar or line graph. Users can compare recorded time against applicable goals or view adherence percentages over a selected date range.
  • Activity Statistics: Displays a table comparing activities using the following information:
    • Activity name.
    • Total time logged.
    • Current daily or weekly target.
    • Average time logged.
    • Goal adherence rate.
  • Future Projections: Displays an estimated cumulative time total for a selected activity and future date. A line graph illustrates historical time records with a solid line and estimated future progress with a dashed line. Current and projected totals are displayed alongside the graph. The estimate is based on the activity's recent daily average, as defined by the analytics subsystem.
  • Filtering Controls: Allow users to select activities, activity statuses, and date ranges for the different reporting sections.
User Interactions
  • Select an activity or all activities and a date range to update the Current Progress statistics.
  • Use the graph controls to select activities, switch between recorded time and adherence percentages, choose a bar or line graph, and adjust the date range.
  • Filter the Activity Statistics table by activity status and reporting period.
  • Select an activity and future date in the Future Projections section to display an estimated cumulative time total and projection graph.
  • View historical progress using the goals that were applicable during each reporting period, even if those goals have since been revised.
  • Reporting sections update independently based on their selected filters.
  • If an activity has insufficient recorded history, the Future Projections section displays a message explaining that an estimate is not yet available.

2.2 Modal Dialogs

Modal dialogs allow users to create, view, edit, and delete activities and time records without navigating away from the current page.

2.2.1 Log Time Modal

The Log Time modal allows users to record time spent on an activity without navigating away from their current page. It can be accessed through the sidebar or logging buttons associated with individual activities. Clicking a logging button associated with a specific activity automatically selects that activity in the modal.

Related requirements: FR-09, FR-10, FR-18

Key Components
  • Activity Selection: A dropdown menu for selecting the activity associated with the time record. Will only display active or suspended activities. Archived activities cannot receive new time records. When opened from an individual activity, that activity is automatically selected.
  • Date and Time: A date and time picker that defaults to the present.
  • Duration: A numerical input field with a dropdown for selecting minutes or hours.
  • Notes: An optional text field for adding information about the recorded session.
  • Action Buttons: Save, Cancel, and Close controls for submitting or dismissing the form.
User Interactions
  • Select an activity from the dropdown menu. When opened from an individual activity, that activity is automatically selected.
  • Select the date and time of the session using the date and time picker, or leave untouched for present.
  • Enter the session duration and select minutes or hours.
  • Optionally enter notes describing the session.
  • Click Save to validate and save the time record. The modal closes and affected progress indicators and statistics are updated.
  • Click Cancel or the close button to dismiss the modal without saving.

2.2.2 Edit Log Modal

The Edit Log modal allows users to modify or delete an existing time record. The form displays the record's saved information, which users can update without navigating away from the current page.

Related requirements: FR-11, FR-12, FR-18

Key Components
  • Activity Name: Displays the activity associated with the time record. This field cannot be changed after the record has been saved.
  • Date and Time: Displays the saved date and time, which can be modified using the date and time picker.
  • Duration: Displays the saved duration in an editable numerical field, with a dropdown for selecting minutes or hours.
  • Notes: Displays any existing notes in an editable text field.
  • Action Buttons: Save, Delete, Cancel, and Close controls for updating, deleting, or dismissing the record.
User Interactions
  • Modify the date, time, duration, or notes associated with the selected record.
  • The associated activity is displayed as a read-only field and cannot be reassigned to another activity.
  • Click Save to validate and save the changes. Affected progress indicators and statistics are recalculated.
  • Click Delete to request confirmation before permanently removing the time record.
  • Click Cancel or the close button to dismiss the modal without saving changes.

2.2.3 Notes Modal

The Notes modal allows users to view the complete notes associated with an individual time record without opening the editing interface.

Related requirements: FR-10, FR-13

Key Components
  • Record Information: Displays the activity name, recorded duration, and date and time of the selected session.
  • Notes: Displays the complete notes associated with the selected time record in a read-only text area.
  • Close Button: Allows users to dismiss the modal and return to the previous page.
User Interactions
  • Click the notes associated with a time record to open the Notes modal.
  • Read the complete notes without modifying the saved record.
  • Click the close button to dismiss the modal and return to the previous page.

2.2.4 Edit Activity Modal

The Edit Activity modal allows users to modify an existing activity's name and goal, as well as manage its current status or delete the activity. The form displays the activity's existing information and can be accessed without navigating away from the current page.

This modal doubles as the form for creating new activities. When creating a new activity, the modal will have a different title and the fields will not be pre-filled. The status-changing buttons will also not be available.

Related requirements: FR-01, FR-03, FR-04, FR-05, FR-06, FR-07, FR-08, FR-19, FR-20

Key Components
  • Activity Name: An editable text field containing the activity's current name.
  • Target: A numerical input field for the target duration, along with dropdown menus for selecting minutes or hours and a daily or weekly goal interval.
  • Action Buttons: Save, Suspend, Archive, Delete, Cancel, and Close controls. The available status actions depend on the activity's current status.
User Interactions
  • Modify the activity name or its current goal's target duration and interval.
  • Click Save to validate and save changes. Changes to the goal create a new goal version while preserving previous versions and historical comparisons.
  • Click Suspend to suspend the activity and its current goal. Suspended activities display a Resume button instead.
  • Click Archive to archive the activity while retaining its goals and time records. Archived activities can be restored using a Restore button.
  • Click Delete to request confirmation before permanently deleting the activity, its goals, and associated time records.
  • Click Cancel or the close button to dismiss the modal without saving changes.

3. Interaction Design

TEMPO's interface provides controls for managing activities, recording time, and reviewing progress. User interactions are designed to be straightforward, with input validation, feedback messages, and confirmation dialogs to help prevent errors and unintended changes.

3.1 Forms and Input Validation

TEMPO validates user input before saving activities, goals, or time records. Forms use clearly labeled fields and display error messages when required information is missing or invalid.

  • Activity Creation: Requires a nonempty activity name and a valid daily or weekly goal.
  • Goal Management: Requires a positive target duration and a selected daily or weekly interval.
  • Time Logging: Requires an activity, a valid date, and a positive duration. Users can enter durations in minutes or hours.
  • Editing: Forms display existing values when editing saved information. The activity associated with an existing time record cannot be changed.
  • Invalid Input: The form remains open and displays an error message identifying the field that needs correction.

3.2 User Feedback and Confirmation

The interface provides feedback when users create, modify, or delete information. Progress indicators and statistics are updated to reflect changes to saved time records.

  • Successful Actions: Saving an activity, goal, or time record displays a confirmation message and closes the corresponding modal.
  • Progress Updates: Creating, editing, or deleting time records updates affected progress bars, totals, averages, and charts.
  • Deletion Confirmation: Deleting an activity or time record requires confirmation before the information is permanently removed.
  • Canceling Actions: Cancel and Close buttons dismiss modal dialogs without saving unsaved changes.
  • Error Feedback: If an operation fails, the interface displays an error message rather than indicating that the action was successful.

3.3 Activity and Goal States

TEMPO supports active, suspended, and archived activities. The interface uses "Paused" as the user-facing label for the SUSPENDED status. Each activity's status also applies to its current goal.

  • Active: Activities appear in the Dashboard's progress section and can receive new time records.
  • Paused: Activities are temporarily suspended while retaining their goals and recorded history. Users can still log time for paused activities, but suspended days do not count toward goal completion. Activities can be resumed through the editing modal.
  • Archived: Activities remain accessible through the All Activities page but cannot receive new time records or be edited until restored. Their goals and historical records are preserved.
  • Goal Revisions: Changing an activity's target duration or interval creates a new goal version. Previous versions are retained so historical progress comparisons remain unchanged.

4. Design Rationale

The following design decisions explain the reasoning behind TEMPO's interface layout and interactions, including how these choices support the system requirements.

DD-60: Dashboard-Centered Design

Related requirements: FR-02, FR-14, NFR-03

TEMPO uses a dashboard as its main landing page, displaying current goal progress, time totals, and recent time records. Users can also record time directly from the activity cards. This reduces the need to navigate between pages for common actions. The dashboard only displays recent records and current progress to avoid overcrowding the interface, while more detailed information remains accessible through other pages.

DD-61: Persistent Sidebar Navigation

Related requirements: FR-02, FR-13, NFR-03

A persistent sidebar provides navigation between the application's main pages and direct access to frequently used activities. The sidebar displays a limited number of activity shortcuts to prevent it from becoming excessively long. Users with additional activities must access them through the All Activities page, but this keeps the navigation organized and consistent.

DD-62: Modal-Based Data Entry

Related requirements: FR-01, FR-04, FR-09, FR-11, NFR-03

TEMPO uses modal dialogs for creating and editing activities and recording or modifying time entries. These dialogs allow users to complete common actions without leaving their current page. Modals have limited space compared with full pages, but TEMPO's data entry forms are relatively simple and do not require extensive controls.

DD-63: Separate Overview and Detailed Reporting

Related requirements: FR-13, FR-14, FR-15, FR-16, NFR-05

TEMPO separates current progress summaries from detailed historical reporting. The Dashboard provides an overview of current goals, individual activity pages display activity-specific progress and statistics, and the Reports & Statistics page provides broader comparisons and historical trends. This organization prevents the Dashboard from becoming cluttered, although users must navigate to separate pages to access more detailed reports.

5. Usability and Accessibility

TEMPO's interface is designed to be straightforward and consistent, with shared navigation, clearly labeled controls, and quick access to frequently used actions. These design choices support NFR-03, which requires first-time users to independently create an activity, assign a goal, and record time.

To support NFR-04, navigation menus, forms, and activity management controls will be accessible through keyboard input. Form fields will have descriptive labels, and progress bars and graphs will be accompanied by numerical values or written summaries so that information is not conveyed through visuals alone.

Modal dialogs support keyboard navigation and maintain focus within the dialog while it is open. When a modal closes, keyboard focus returns to the control that opened it.
